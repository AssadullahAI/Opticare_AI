# 🚀 OptiCare AI - QUICK START GUIDE

## ⏱️ 5-Minute Setup

### Step 1: Install Python (If Needed)
Download Python 3.10+ from [python.org](https://python.org)

### Step 2: Create Project
```bash
mkdir eye_ai_exceptional
cd eye_ai_exceptional
```

### Step 3: Copy All Files
Place all project files in this directory

### Step 4: Create Virtual Environment
```bash
python -m venv venv
```

### Step 5: Activate Virtual Environment
**Windows:**
```bash
venv\Scripts\activate
```

**Mac/Linux:**
```bash
source venv/bin/activate
```

### Step 6: Install Dependencies
```bash
pip install -r requirements.txt
```

**⏳ This takes 3-5 minutes (downloads AI models)**

### Step 7: Run the App
```bash
streamlit run app.py
```

**🎉 Done!** Browser opens automatically.

## 🐛 Quick Troubleshooting

**Error: "No module named X"**
```bash
pip install -r requirements.txt
```

**Error: "Port already in use"**
```bash
streamlit run app.py --server.port 8502
```

**App runs slow**
- First run is slower (loading models)
- Subsequent runs are fast (cached)
