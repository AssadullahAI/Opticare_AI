## 💡 INTERVIEW TALKING POINTS

### Technical Depth

**Q: "Tell me about a challenging technical problem you solved."**

*A: "In the OptiCare AI project, I needed to implement semantic search over 1,300+ medical sentences with sub-second response times. I used sentence transformers to convert text into 384-dimensional embeddings and FAISS for efficient L2 distance search. The challenge was balancing accuracy and performance - I implemented multi-level caching and batch processing to achieve <500ms response times while maintaining 85%+ relevance accuracy."*

### System Design

**Q: "How did you design for scalability?"**

*A: "I implemented a three-tier architecture: data layer with caching, AI/ML layer with model persistence, and application layer with session management. The system uses Streamlit's resource caching for models, pickle for data persistence, and FAISS for O(log n) search complexity. This allows the system to handle 50+ concurrent users with minimal resource overhead."*

### Medical Domain

**Q: "How did you handle safety in a medical application?"**

*A: "Safety was paramount. I built a multi-tier emergency detection system with CRITICAL, HIGH, and URGENT severity levels. Each has specific keywords and action protocols. I also implemented content filtering, comprehensive medical disclaimers, and 'when to see a doctor' guidelines. The system never claims to diagnose - it educates while encouraging professional consultation."*
