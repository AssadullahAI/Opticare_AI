# OptiCare AI – System Architecture

## Overview
OptiCare AI is a modular medical AI system focused on eye disease education and analysis.

## Components
- Streamlit UI
- NLP Chatbot (Sentence Transformers + FAISS)
- Emergency Symptom Detection
- Image-based Eye Disease Analysis
- Config-driven architecture

## Safety
- Medical disclaimer enforced
- Emergency keyword detection
- No automated diagnosis

## Tech Stack
- Python 3.10
- Streamlit
- PyTorch
- FAISS
- Sentence Transformers
